# Language learning apps

Two personal study apps, each in its own folder with its own README:

| Folder | App | What it teaches |
|---|---|---|
| [English/](English/) | **Fluent Path** | English from B1 to C1: lessons, spaced repetition, adaptive daily sessions, natural-voice listening |
| [Japanese/](Japanese/) | **Hanamaru** | A daily Japanese program from N5 to N2 |

Each app runs on its own (`npm install`, then see its README). Learner data (SQLite databases,
recordings, generated audio) lives in each app's ignored data folders and is not part of the repository.
